\# Система менеджмента информационной безопасности



\## Назначение репозитория



Репозиторий предназначен для ведения и контроля документированной информации системы менеджмента информационной безопасности (СМИБ).



\## Структура документации



\- `01-politika` — политика информационной безопасности верхнего уровня.

\- `02-chastnye-politiki` — частные политики информационной безопасности.

\- `03-procedury` — процедуры и регламенты.

\- `04-instrukcii` — инструкции, шаблоны и чек-листы.

\- `05-zapisi` — шаблоны и записи, подтверждающие выполнение процессов СМИБ.



\## Порядок внесения изменений



Изменения в документы вносятся через отдельную ветку Git. Каждое изменение должно быть зафиксировано информативным коммитом с указанием сути изменения и его причины.



Для утверждения изменений используется запрос на слияние (Merge Request / Pull Request) с обязательным рецензированием.



Утверждённые редакции документов маркируются тегами Git.



\## Контроль версий



История коммитов используется для определения автора, даты и содержания изменений, а также для восстановления предыдущих редакций документов.
